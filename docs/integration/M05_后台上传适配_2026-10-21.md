# M05 后台上传补充记录

本条替代之前记录中“上传禁用待适配”的状态。仅修改 admin/src/** 与本补充记录；无数据库、存储、根目录或后端修改。

- 新增 src/lib/api/uploads.ts，复用M01预签、当前状态、同源PUT、完成、轮询至ready协议；仅允许activity_cover/reward_image，JPEG/PNG/WebP，10MB。
- 预签method必须PUT，assetId必须UUID，pathname必须精确匹配/api/v1/uploads/local/<assetId>。即使预签包含H5 origin3001，也仅取pathname+search向后台同源3003请求，不请求外部origin。
- 字节请求携带requiredHeaders与统一客户端新取CSRF。预签、状态、complete沿用统一客户端刷新、错误处理和CSRF。
- 同一文件/用途的失败重试保留operationKey；ready直接返回、validating仅轮询，不再PUT。网络失败、校验失败、异常状态及超时均提示错误，不宣布成功。
- AssetPicker详情改用/admin/media-assets/:id；列表与详情由后端提供管理员公共素材DTO，status查询仍使用仅当前上传者的/uploads/:id。读取readUrl字段；不暴露avatar/meal_photo。
- 原AdminAssets上传入口重新启用；完成轮询至ready才显示成功并刷新列表。
