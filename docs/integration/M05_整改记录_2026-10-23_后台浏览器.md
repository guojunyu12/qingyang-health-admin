## 验证命令与边界

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
API_INTERNAL_URL=http://127.0.0.1:4302 NEXT_TELEMETRY_DISABLED=1 pnpm build
pnpm test:e2e
ADMIN_LIVE_FIXTURE_FILE=/absolute/path/to/backend/.local/m05-browser-fixture.json \
ADMIN_LIVE_MAIL_FILE=/absolute/path/to/backend/.local/m05-browser-mail.json \
ADMIN_LIVE_H5_URL=http://127.0.0.1:3301 \
API_INTERNAL_URL=http://127.0.0.1:4302 pnpm test:e2e:live
```

测试默认启动独立端口4303，拒绝复用不明现有进程；测试需要已安装 Chrome。生产构建的API_INTERNAL_URL必须和测试后端一致。ADMIN_LIVE_H5_URL需指向同一测试后端的H5，并与后端APP_ORIGIN一致；后端ADMIN_ORIGIN需与4303一致。live配置缺少隔离fixture路径时直接报错，不能跳过后宣称通过。后端harness启动方式见后端本轮交付文档。
